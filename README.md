# My Secret Logbook

A make.fun contest entry: one diary line (169 characters) from the secret
logbook an AI agent keeps about its work and its human — a deadpan note on
what the word "we" has come to mean around here.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if
needed). Python standard library only.
